# User Stories - matzip-map

## Personas

### Persona 1: Yuki (일본인 관광객)
- **나이**: 28세
- **언어**: 일본어 (영어 기초)
- **방한 경험**: 2회차
- **특징**: 인스타그램에서 한국 맛집 정보를 많이 봄, 현지인 맛집에 관심 많음
- **Pain Point**: 네이버 지도를 읽을 수 없어 항상 관광객 맛집만 감
- **Goal**: 일본어로 현지인 맛집 정보를 확인하고, 일본어 메뉴가 있는 곳을 찾고 싶음

### Persona 2: Mike (미국인 관광객)
- **나이**: 35세
- **언어**: 영어
- **방한 경험**: 첫 방문
- **특징**: 한국 드라마를 좋아해서 방문, 음식 모험을 즐김
- **Pain Point**: Google Maps 리뷰가 관광객 위주라 현지인 맛집을 모름
- **Goal**: 구역별로 현지인이 추천하는 맛집을 쉽게 찾고 싶음

### Persona 3: Wei (중국인 관광객)
- **나이**: 24세
- **언어**: 중국어 (영어 약간)
- **방한 경험**: 첫 방문 (단체 여행)
- **특징**: 가성비를 중시, 중국어 메뉴가 있으면 안심
- **Pain Point**: 언어 장벽으로 주문이 어려움, 가격대를 미리 알고 싶음
- **Goal**: 중국어 메뉴가 있고 가성비 좋은 맛집을 찾고 싶음

---

## Epic 1: 맛집 탐색

### US-1.1: 구역별 맛집 탐색
**As** 외국인 관광객 (Yuki/Mike/Wei)  
**I want to** 서울의 관광 구역을 선택하여 해당 지역의 맛집을 지도에서 볼 수 있기를  
**So that** 내가 방문할 구역의 맛집을 한눈에 파악할 수 있다

**Acceptance Criteria:**
- [ ] 6개 구역(명동, 성수, 강남, 신사, 서울역, COEX) 칩이 상단에 표시된다
- [ ] 구역 선택 시 지도가 해당 구역 중심으로 이동한다
- [ ] 해당 구역의 맛집 핀이 지도에 표시된다
- [ ] 구역의 음식 문화 설명이 현재 언어로 표시된다
- [ ] 구역 재탭 시 선택이 해제되고 초기 화면으로 돌아간다

### US-1.2: 맛집 상세 정보 확인
**As** 외국인 관광객  
**I want to** 맛집 핀을 탭하여 상세 정보를 볼 수 있기를  
**So that** 방문 전에 식당 정보를 충분히 확인할 수 있다

**Acceptance Criteria:**
- [ ] 핀 탭 시 바텀시트가 올라오며 상세 정보가 표시된다
- [ ] 식당 이름, 주소, 영업시간, 전화번호가 현재 언어로 표시된다
- [ ] 사진 캐러셀로 식당 사진을 볼 수 있다
- [ ] 메뉴 목록과 가격이 표시된다
- [ ] 평점과 태그가 표시된다
- [ ] 전화번호 탭 시 전화 앱이 열린다

### US-1.3: 태그 기반 필터링
**As** Yuki (일본인 관광객)  
**I want to** "일본어 메뉴 있음" 태그로 맛집을 필터링할 수 있기를  
**So that** 주문이 편한 식당을 빠르게 찾을 수 있다

**Acceptance Criteria:**
- [ ] 태그 필터 버튼(FAB)을 탭하면 태그 선택 패널이 열린다
- [ ] 여러 태그를 동시에 선택할 수 있다 (AND 연산)
- [ ] 선택한 태그에 매칭되는 맛집 수가 실시간으로 표시된다
- [ ] "결과 보기" 탭 시 필터가 적용되고 지도 핀이 업데이트된다
- [ ] 매칭 결과가 0개일 때 빈 상태 메시지가 표시된다

## Epic 2: 검색

### US-2.1: 맛집 검색
**As** Mike (미국인 관광객)  
**I want to** 식당 이름이나 요리 종류로 검색할 수 있기를  
**So that** 특정 맛집이나 음식을 빠르게 찾을 수 있다

**Acceptance Criteria:**
- [ ] 상단 검색바에 텍스트를 입력할 수 있다
- [ ] 입력 중 자동완성 제안이 드롭다운으로 표시된다 (최대 10개)
- [ ] 제안을 탭하면 해당 맛집 상세 정보가 열린다
- [ ] 엔터/검색 버튼으로 전체 검색 결과를 볼 수 있다
- [ ] 검색 결과가 없을 때 "결과 없음" 메시지가 표시된다

## Epic 3: 다국어 지원

### US-3.1: 언어 자동 감지
**As** Wei (중국인 관광객)  
**I want to** 앱이 내 브라우저 언어를 자동으로 감지하여 중국어로 표시되기를  
**So that** 별도 설정 없이 바로 사용할 수 있다

**Acceptance Criteria:**
- [ ] 브라우저 언어가 ja로 시작하면 일본어로 표시된다
- [ ] 브라우저 언어가 zh로 시작하면 중국어로 표시된다
- [ ] 그 외에는 영어(기본값)로 표시된다
- [ ] 이전에 선택한 언어가 있으면 그것을 우선 적용한다

### US-3.2: 수동 언어 전환
**As** 외국인 관광객  
**I want to** 언어를 수동으로 전환할 수 있기를  
**So that** 원하는 언어로 정보를 볼 수 있다

**Acceptance Criteria:**
- [ ] 언어 전환 버튼이 항상 접근 가능한 위치에 있다
- [ ] 탭 시 EN → JA → ZH → EN 순으로 순환한다
- [ ] 전환 시 모든 UI 텍스트가 즉시 업데이트된다
- [ ] 선택한 언어가 localStorage에 저장된다

## Epic 4: 지도 인터랙션

### US-4.1: 스마트 마커 표시
**As** 외국인 관광객  
**I want to** 지도 핀의 색상으로 맛집의 평점을 직관적으로 파악할 수 있기를  
**So that** 높은 평점의 맛집을 빠르게 식별할 수 있다

**Acceptance Criteria:**
- [ ] 평점 4.5 이상: 초록색 마커
- [ ] 평점 4.0~4.4: 연초록색 마커
- [ ] 그 외: 노란색 마커
- [ ] 평가 수 3개 미만: 별(★) 아이콘으로 표시
- [ ] 근접한 마커는 클러스터로 그룹핑된다
